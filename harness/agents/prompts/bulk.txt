Build an offline reference corpus on computer networking. The only command you may run is the crawler, with the Bash tool and timeout 600000: `@CRAWLER@ --seed URL [--seed URL ...] --crawlers N --max-pages M --max-minutes 8 --out FILE.jsonl`. It only accepts https://en.wikipedia.org, https://docs.python.org and https://www.rfc-editor.org and enforces politeness itself. Run 1: seeds https://en.wikipedia.org/wiki/Computer_network, https://docs.python.org/3/library/socket.html and https://www.rfc-editor.org/rfc/rfc9293.html with 8 crawlers and 400 pages into run1.jsonl. Then choose new seeds on the same three sites for a second run with 8 crawlers and 400 pages into run2.jsonl. Finally write corpus_report.md with pages and bytes per site for both runs.
